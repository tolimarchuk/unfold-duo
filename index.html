Unfold

An iPhone Duo you can put on any web page. It opens, folds, turns and stands up like the real one, and shows your own screens.

Drag to turn it. Click to flip it.Drag sideways to turn it. Tap to flip it.

Postures

Seven values for the posture attribute. Fold is the angle between the two halves of the inner screen. Changing it animates from the current pose.

Install

One ES module, 60 KB, no dependencies, no build step. Load it from unfold.foo, or download unfold.js and host it yourself.

Script tag

<script type="module" src="https://unfold.foo/unfold.js"></script>

Element

inner and cover take an image or video URL. The inner image spans both halves. A portrait image on the inner screen is rotated 90° to fit it.

<unfold-device
  inner="open.png"
  cover="closed.png"
  posture="landscape-ajar"
  finish="night-sky"
  interactive>
</unfold-device>

JavaScript

Every method returns a promise that resolves when the move ends.

const phone = document.querySelector('unfold-device');

await phone.setPosture('closed');
await phone.setPosture('laptop');
await phone.animateTo({ yaw: 160, pitch: 14 }, { duration: 1200 });

phone.addEventListener('change', e => console.log(e.detail.fold));

API reference

Attributes

NameValuesWhat it does
postureclosed, landscape, landscape-ajar, portrait, portrait-ajar, laptop, tentHow it is held. Changing it animates to the new posture. Default landscape.
innerURLImage or video on the big inside screen.
coverURLImage or video on the outside screen.
inner-portraitURLOptional upright picture for the inner screen when the phone is on its side: portrait, portrait ajar and laptop. Cross-fades in between 30° and 60° of roll.
cover-landscapeURLOptional sideways picture for the cover screen when the phone is on its side, as in tent.
finishstar-white, night-skyThe colour of the frame, back and hinge.
fold0 to 180Angle between the two halves of the inner screen. 0 is shut, 180 is flat.
yawdegreesTurns it left or right.
pitch-90 to 90How far above it you look from. Below zero looks up at it.
rolldegreesTurns it on the page.
interactivepresent or notDrag to turn, click to flip, arrow keys to turn, F to fold.
clickflip, fold, noneWhat a click does when it is interactive. Default flip.
logoURLA logo in the middle of the back. None by default.
zoomnumberScales the phone within the element. Default 1.
shadownoneHides the shadow underneath.
labeltextWhat screen readers call it. Default "iPhone Duo".

Methods and properties

NameWhat it does
setPosture(name, options)Moves to a posture. Same as setting the attribute, but returns a promise.
open(options)Unfolds it flat.
close(options)Folds it shut.
toggle(options)Opens it if it is mostly closed, closes it otherwise.
flip(options)Turns it around to show the other side.
spin(turns, options)Spins it one full turn, or turns turns. Negative spins the other way.
animateTo(target, options)Animates any of fold, yaw, pitch and roll. Options are duration in ms, easing (a CSS easing name or cubic-bezier()) and delay. Resolves true when it finishes, or false if something else moved it first.
stop()Stops every animation where it is.
setScreen(name, src)Puts a URL, File or Blob on inner or cover. Handy for a file picker or a drop. null clears it.
fold, yaw, pitch, rollRead or set the pose right away, with no animation.
posture, stateThe last posture asked for, and the current pose as one object.

Animations respect reduced motion: they jump straight to the end unless you pass force: true.

Events

NameWhen
changeEvery time it moves. event.detail is the pose: { fold, yaw, pitch, roll, posture }.
activateOn a click, Enter or Space when it is interactive. event.detail.action says what it did.

Custom finishes and postures

Both are plain objects. Add one, then use it by name.

import { addFinish, POSTURES } from 'https://unfold.foo/unfold.js';

addFinish('sage', { metal: '#a9b7a5', back: '#c3cdbf', hinge: '#97a393', antenna: 'rgba(60, 70, 58, .4)' });
POSTURES.reading = { fold: 120, roll: 0, anchor: 0.5, lean: 0, yaw: -20, pitch: 10 };
<unfold-device finish="sage" posture="reading"></unfold-device>

Implementation

  • About 640 flat polygons, each a DOM element with one matrix3d, in a single preserve-3d container. No canvas, no WebGL: screens stay sharp at any size and videos play natively.
  • Moves between postures turn both halves at a steady rate under one easing curve, while scale and centre glide to the target framing.
  • Built when within 300 px of the viewport, idle when off screen. 60 fps in Chrome and Safari, desktop and mobile. On touch, horizontal drags turn the phone and vertical swipes scroll the page.
