Unfold

A foldable phone made of HTML and CSS. Put your own screens on it, then open it, close it and turn it around.

Drag to turn it, click to flip it. Drop a screenshot or video on it to see your own.Drag sideways to turn it, tap to flip it.

Any pose, from a few attributes

Each of these is the same element. They all turn and flip too.

Add it to a page

Copy unfold.js into your project. It is a single ES module with no build step.

Load the script

<script type="module" src="unfold.js"></script>

Add a phone

Give it a picture or a video for each screen. The inner screen spans both halves when it is open.

<unfold-device
  inner="open.png"
  cover="closed.png"
  fold="0"
  interactive>
</unfold-device>

Move it

Every method returns a promise, so steps can run one after another.

const phone = document.querySelector('unfold-device');

await phone.open();
await phone.animateTo({ yaw: 160, pitch: 14 }, { duration: 1200 });
await phone.close();

phone.addEventListener('change', e => console.log(e.detail.fold));

Reference

Attributes

NameValuesWhat it does
fold0 to 180How far it is open. 0 is shut, 180 is flat. Default 180.
yawdegreesTurns it left or right. Default -18.
pitch-90 to 90Tips the top towards you or away. Default 8.
rolldegreesRotates it flat on the page. Default 0.
innerURLImage or video on the big inside screen.
coverURLImage or video on the outside screen.
frontURLImage or video on the screen of the regular phone.
modelfoldable, barWhich phone. bar is a regular one-piece phone.
finishblack, silverThe colour of the metal and the back.
orientationlandscape, portraitIn portrait the phone turns on its side as it opens, so the inside screen stands upright.
interactivepresent or notDrag to turn, click to flip, arrow keys to turn, F to fold.
clickflip, fold, noneWhat a click does when it is interactive. Default flip.
zoomnumberScales the phone within the element. Default 1.
shadownoneHides the shadow underneath.
labeltextWhat screen readers call it. Default "Foldable phone".

Methods and properties

NameWhat it does
open(options)Unfolds it flat.
close(options)Folds it shut.
toggle(options)Opens it if it is mostly closed, closes it otherwise.
flip(options)Turns it around to show the other side.
spin(turns, options)Spins it one full turn, or turns turns. Negative spins the other way.
animateTo(target, options)Animates any of fold, yaw, pitch and roll. Options are duration in ms, easing (a CSS easing name or cubic-bezier()) and delay. Resolves true when it finishes, or false if something else moved it first.
stop()Stops every animation where it is.
setScreen(name, src)Puts a URL, File or Blob on inner, cover or front. Handy for a file picker or a drop. null clears it.
fold, yaw, pitch, rollRead or set the pose right away, with no animation.
stateThe current pose as one object.

Animations respect reduced motion: they jump straight to the end unless you pass force: true.

Events

NameWhen
changeEvery time it moves. event.detail is the pose: { fold, yaw, pitch, roll }.
activateOn a click, Enter or Space when it is interactive. event.detail.action says what it did.

Styling

NameWhat it does
width, heightThe element is a block, 16:10 by default. Size it however you like and the phone scales to fit.
--unfold-metalColour of the frame. Overrides the finish.
--unfold-backColour of the back glass.
--unfold-plateauColour of the camera bump.
--unfold-shadowHow dark the shadow is, 0 to 1. Default 0.3.
::part()stage, shadow, screen, back-glass and camera.

Your own phone

Models and finishes are plain objects, measured in millimetres. Add one, then use it by name.

import { MODELS, addModel, addFinish } from './unfold.js';

addFinish('blue', { metal: '#3d4b63', back: '#2b3547', plateau: '#232b39' });
addModel('compact', { ...MODELS.bar, width: 67.6, height: 139.6 });
<unfold-device model="compact" finish="blue" front="home.png"></unfold-device>

Notes

  • The foldable is built to the published size of a book-style foldable: 164.6 by 117.8 mm open, 84.1 by 117.8 mm closed and 11.3 mm thick. It is a likeness, not an official model.
  • It is all plain elements and CSS transforms, worked out in JavaScript each frame. There is no canvas and no WebGL, so screens stay sharp at any size and videos play as they are.
  • Tested in Chrome and Safari, on desktop and on phones. On a touchscreen a sideways drag turns it and a vertical swipe still scrolls the page.
  • Free to use under the MIT license. Not affiliated with any phone maker.
